# Mini Social Media App

A full-stack mini social media platform built with:
- **Backend:** Node.js (Express.js), MongoDB (Mongoose)
- **Frontend:** HTML, CSS (Instagram-style), JavaScript
- **Features:** User authentication, profile edit (bio/avatar), post creation, likes, comments, follow system, search, mobile responsive, and more!

---

## ✨ Features

- User **Registration/Login**
- **Profile Edit:** Update bio and avatar/photo URL
- **Create Post:** Share text posts (with instant feed update)
- **Like & Comment:** Interact with others’ posts, pop animation & “time ago”
- **Delete Post:** Remove your own post anytime
- **Follow/Unfollow:** Discover users, follow, and see your followers/following
- **Followers Modal Popup:** Fancy popup to view your followers
- **Search:** Instantly find users and posts
- **Responsive Design:** Works on mobile, tablet, and desktop
- **Instagram-inspired UI:** Modern gradients, shadows, button hover/active effects, sidebar profile
